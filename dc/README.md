# Design Compiler — Logic Synthesis

This directory contains the Synopsys Design Compiler synthesis flow for the FSM-based vending machine.

## Directory Structure

```text
dc/
├── source/
├── scripts/
├── reports/
├── results/
└── work/
```

---

## Source Files

```text
source/
├── vending_machine.v
└── vending_machine.sdc
```

### RTL

`vending_machine.v` contains the RTL design synthesized by Design Compiler.

### Constraints

`vending_machine.sdc` contains the timing and design constraints.

The primary clock constraint is:

```text
Clock Period = 5 ns
```

The operating condition is:

```text
Process      = TT
Voltage      = 0.85 V
Temperature  = 25 °C
```

---

## Synthesis Script

```text
scripts/synth_vending_machine.tcl
```

The script performs the Design Compiler synthesis flow and generates the required reports and results.

---

## Setup File

```text
work/.synopsys_dc.setup
```

The setup file contains the Design Compiler environment and reference-library configuration.

---

## Running Design Compiler

Navigate to:

```bash
cd dc/work
```

Launch Design Compiler:

```bash
dc_shell -gui
```

From the Design Compiler command prompt:

```tcl
source ../scripts/synth_vending_machine.tcl
```

---

## Synthesis Flow

The synthesis flow includes:

1. Library setup
2. RTL analysis/elaboration
3. Constraint loading
4. Design linking
5. Design optimization
6. Technology mapping
7. Incremental optimization
8. Report generation
9. Synthesized output generation

The synthesis flow uses `compile_ultra`.

---

## Reports

Reports are stored under:

```text
reports/
```

The main reports cover:

- Area
- Power
- Constraints
- Quality of Results
- Timing

---

## Results

Generated synthesis outputs are stored under:

```text
results/
```

These include the synthesized Verilog, compiled design database, and output SDC generated by the synthesis flow.

The synthesized Verilog and SDC are also automatically copied to:

```text
../icc2/source/
```

for use by IC Compiler II.

---

## Technology Library

The design uses the SAED32 RVT standard-cell library at:

```text
TT
0.85 V
25 °C
```

The required proprietary library files are documented under the repository's `ref/` directory but are not included in the public repository.
