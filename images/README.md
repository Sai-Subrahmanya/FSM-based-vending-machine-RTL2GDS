# Project Images

This directory contains screenshots documenting the major stages of the FSM-based vending machine RTL-to-GDSII flow and the Synopsys tools used during the implementation.

## Screenshots

### RTL Verification — VCS

- `01_vcs_simulation_pass.png` — Successful RTL functional simulation
- `02_dve_waveform.png` — DVE waveform analysis and signal verification

### Logic Synthesis — Design Compiler

- `03_dc_synthesis_results.png` — Design Compiler synthesis results and synthesized design

### Physical Design — IC Compiler II

- `04_icc2_floorplan.png` — Initial floorplan
- `05_icc2_power_plan.png` — Power and ground planning
- `06_icc2_placement.png` — Standard-cell placement
- `07_icc2_clock_tree_synthesis.png` — Clock-tree synthesis
- `08_icc2_routing.png` — Routed physical design
- `09_icc2_final_design.png` — Final physical implementation
- `10_clock_tree.png` — Clock-tree visualization and analysis
- `11_shortest_path_arrival_time.png` — Shortest clock path from source and arrival-time analysis
- `12_longest_path_arrival_time.png` — Longest clock path from source and arrival-time analysis

## Purpose

These screenshots provide visual evidence of the RTL verification, logic synthesis, physical design, clock-tree analysis, and final implementation stages of the project.

They complement the Verilog/SystemVerilog source files, TCL scripts, reports, and generated results included in the repository.

## Note

The screenshots are provided for project documentation and reference.

The proprietary SAED32 technology libraries, standard-cell libraries, technology files, and other restricted reference files are not included in this repository.
