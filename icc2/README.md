# Running IC Compiler II

Navigate to:

```bash
cd icc2/work
```

Launch ICC2:

```bash
icc2_shell -gui
```

Run the complete physical-design flow:

```tcl
source ../scripts/run_all.tcl
```

The scripts may also be executed individually when required.

# Physical Design Flow

The complete flow consists of:

```text
Floorplanning
      ↓
Power Planning
      ↓
Placement
      ↓
Clock Tree Synthesis
      ↓
Clock Optimization
      ↓
Routing
      ↓
Filler Insertion
      ↓
PG Repair / Connectivity
      ↓
Final Reports
```

---

## Floorplanning

The floorplan establishes the physical design area, core region, placement boundaries, and initial physical constraints.

---

## Power Planning

Power and ground structures are created for the design, including power rings, power meshes, and standard-cell power connections.

---

## Placement

Standard cells are placed within the core region.

Placement optimization is performed to improve physical implementation quality and timing.

---

## Clock Tree Synthesis

The clock network is synthesized and optimized to distribute the clock signal through the design.

Clock latency and clock-tree characteristics are subsequently analyzed.

---

## Routing

The design undergoes global and detailed routing.

The routing stage connects the placed standard cells and clock network according to the technology routing rules.

---

## Filler Insertion

Filler cells are inserted after routing to maintain physical and well continuity requirements.

---

## PG Repair

Power/ground connectivity is checked and repaired where required.

---

# Clock Tree Analysis

The implemented clock tree can be inspected through the ICC2 GUI.

The procedure used in this project is:

1. Select **Highlight → Color By → Clock Tree**.
2. Select the required clock in the Clock Tree window.
3. Click **Apply**.
4. Open **Window → Clock Tree Analysis Window**.
5. Right-click the clock.
6. Select **Clock Tree Latency Graph of Selected Corner**.
7. Click **OK**.
8. Right-click the clock and select **Expand All**.
9. Select **Highlight Longest Path from Source**.
10. Select **Highlight Shortest Path from Source**.

This allows the clock-tree structure, latency, and longest/shortest source paths to be visually inspected.
